# 📷 Smart Barcode & QR Hub | ماسح ومولد الباركود الذكي

تطبيق ويب متكامل، فوري ومجاني 100% لمسح وتوليد جميع أنواع الباركود ورموز الاستجابة السريعة (QR Codes) مباشرة من المتصفح (Client-Side) بدون الحاجة إلى خوادم وسيطة أو اشتراكات في خدمات سحابية مدفوعة.

---

## ✨ المميزات الرئيسية

1. **📷 مسح فوري مباشر عبر الكاميرا (Live Camera Scanner):**
   - استجابة فورية بدون أي تأخير شبكي.
   - دعم التبديل بين الكاميرات (الأمامية / الخلفية) وتفعيل الفلاش (Torch).
   - صوت تنبيه مخصص (Beep) واهتزاز هابتي (Haptic Feedback).
   - وضع المسح المستمر مع منع تكرار نفس الرمز في أجزاء من الثانية.

2. **🖼️ مسح الصور والملفات (Image & Document Scanner):**
   - سحب وإفلات الصور (Drag & Drop) أو تصفح الملفات.
   - دعم لصق الصور من الحافظة مباشرة (`Ctrl + V`).

3. **🖨️ مولّد أكواد شامل (Barcode & QR Generator):**
   - **QR Code:** (روابط مواقع URL، نصوص، شبكات واي فاي WiFi، بطاقات اتصال vCard، واتساب، بريد إلكتروني، أرقام هواتف).
   - **1D Barcodes:** (Code 128, EAN-13, UPC-A, Code 39, ITF-14).
   - تخصيص الألوان والحجم، ومستويات تصحيح الأخطاء.
   - تنزيل بجودة فائقة (PNG / SVG) أو طباعة مباشرة.

4. **📋 سجل المسح والتصدير (Scan History & Export):**
   - حفظ تلقائي لكافة العمليات في التخزين المحلي للمتصفح (LocalStorage).
   - تصدير السجل إلى ملفات **Excel / CSV** أو **JSON**.
   - نسخ فوري أو فتح الروابط مباشرة.

5. **🎨 واجهة مستخدم فائقة العصرية:**
   - دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
   - الوضع الليلي والنهاري (Dark / Light Theme).
   - متجاوب 100% مع الهواتف الذكية والأجهزة اللوحية والكمبيوتر.

## 🚀 كيفية التشغيل

التطبيق مصمم ليكون **مستقلاً بالكامل (Standalone)** دون الحاجة لتثبيت بيئات تشغيل معقدة:

### 1. التشغيل المحلي الفوري:
- افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Safari, Firefox).
- *ملاحظة:* للوصول للكاميرا في بعض المتصفحات، يُفضل تشغيله عبر سيرفر محلي بسيط أو استضافة تدعم HTTPS أو `localhost`.

### 2. التشغيل عبر خادم محلي سريع (Node.js أو Python):
```bash
# باستخدام Python:
python -m http.server 8080

# أو باستخدام Node.js (npx):
npx serve
```
ثم افتح: `http://localhost:8080`

### 3. رفعه على موقعكم أو استضافتكم (Hostinger, cPanel, Vercel, Netlify):
- كل ما عليك فعله هو رفع مجلد المشروع كاملاً إلى مجلد `public_html` أو إضافته كصفحة في موقعكم.
- تأكد من تفعيل شهادة الأمان **HTTPS** على موقعكم ليعمل إذن الكاميرا بشكل سليم على الهواتف.
